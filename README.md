# UVC VoiceChanger

Raspberry Pi port of the s60sc voice changer. A Sound Blaster Play 3 is the microphone and the headphone output.

`original source/` is a local clone of [RandomActsofFrank/UVC_VoiceChanger](https://github.com/RandomActsofFrank/UVC_VoiceChanger), kept as a reference and left out of this repo. The app itself is in `pi/`. See `pi/README.md` to run it.

The Pi app is AGPL-3.0, the same license as the ESP32 original.
